# WorkBee

A Flutter app for connecting students with short projects and micro gigs.

## Run

```powershell
flutter pub get
flutter run
```

## Structure

```text
lib/
  main.dart
  models/
  views/
  controllers/
  services/
  widgets/
test/
```
